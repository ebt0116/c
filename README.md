# 教室投影時鐘

給教室投影機用的全螢幕網頁，在畫面最上方六分之一顯示時間、日期、當日課表、上下課進度和學測倒數。下方五分之六保持全黑，不影響投影其他內容。

**網址：** https://ebt0116.github.io/c/

整個網頁只有一個檔案 `index.html`，不需要安裝任何東西，也不需要網路以外的資源（字體用電腦本機的）。

---

## 使用方式

1. 用 Chrome 或 Edge 打開上面的網址。
2. **點一下畫面**，或按鍵盤 **F**，進入全螢幕。再點一次或再按 F 離開。
3. 讓它開著即可，時間每秒自動更新，跨日也會自動換課表。

> 全螢幕必須由人點擊或按鍵觸發，這是瀏覽器的規定，網頁沒辦法開啟後自動全螢幕。

---

## 畫面配置

畫面上方 1/6 分成左右兩半，**正中央留一條縫**（寬度為螢幕寬的 3%），用來避開牆面中間的突起。左右兩半寬度強制相等，所以縫永遠在正中央。

```
┌──────────────────────────────┬──┬──────────────────────────────┐
│ 12:26   11月24日 星期二 ━━━━━━ │  │ 倒數58天        國軍人才招募專線 │
│ ━━━━━   物理 物理 國文 選修 …  │  │                    0800-000-050 │
└──────────────────────────────┴──┴──────────────────────────────┘
          左半                   縫              右半
```

### 左半

| 元素 | 說明 |
|---|---|
| **時間** | 只顯示時與分（24 小時制，如 `08:05`）。數字等寬，跳動時不會左右晃。 |
| **時間下方進度條** | 這一分鐘過了多少，每秒往右長，滿了歸零。 |
| **日期星期** | 格式為 `11月24日 星期二`，靠左，頂端和時間頂端切齊。 |
| **日期右方進度條** | 目前這一段（上課或下課）過了多少，從左往右填滿。見下方「上下課時間」。 |
| **課表** | 當天的課，每節兩個字：第一個字大、第二個字小，底部切齊，左右撐滿、間距自動分配。**正在上的那節是白色，其他是灰色。** 課表底部和時間下方的進度條底部切齊。 |

### 右半

| 元素 | 說明 |
|---|---|
| **學測倒數** | `倒數XX天`，字級是時間的 1/1.1（時間比倒數大 10%）。 |
| **國軍人才招募專線** | 兩行，靠右對齊，字級和課表大字相同。 |

右半整體比左半多往下一些，上方留白是左半的兩倍。

### 字體與顏色

- 背景純黑 `#000`，文字與進度條純白 `#fff`。
- 課表非目前節次為灰色 `#666`；進度條底色為深灰 `#333`。
- 字體優先使用思源黑體（Noto Sans TC），沒有就用微軟正黑體。
- 所有文字字重 700。**只有中文字**額外加一層很細的描邊讓筆畫稍粗，數字和符號不受影響。

### 尺寸比例

所有尺寸都由一個基準值 `--col` 推算，所以不同解析度、不同比例的螢幕都會等比例縮放。以時間字級為 100% 來看：

| 元素 | 相對時間字級 |
|---|---|
| 時間 | 100% |
| 倒數 | 約 91%（時間比它大 10%） |
| 日期星期、課表大字、招募專線 | 約 43% |
| 課表小字 | 約 20% |
| 左半上方留白 | 12% |
| 右半上方留白 | 24% |

在 1920×1080 螢幕上，時間字高約 104px，整塊區域高 180px。

## 上下課時間

每節 50 分鐘：

| 節 | 時間 |
|---|---|
| 1 | 08:00 – 08:50 |
| 2 | 09:00 – 09:50 |
| 3 | 10:10 – 11:00 |
| 4 | 11:10 – 12:00 |
| 5 | 13:10 – 14:00 |
| 6 | 14:10 – 15:00 |
| 7 | 15:10 – 16:00 |
| 8 | 16:10 – 17:00 |

**上下課進度條**把一天切成一段一段，每段各自從 0% 填到 100%：

- **上課**：每節一段，50 分鐘。
- **一般下課**：每 10 分鐘一段。第 2、3 節之間有 20 分鐘，會切成兩段各 10 分鐘。
- **午休**（12:00 – 13:10）：切成 30 分 + 30 分 + 10 分三段（12:00–12:30、12:30–13:00、13:00–13:10）。
- **08:00 以前、17:00 以後**：進度條空白，課表全灰。

下課時間課表全部是灰色，不會先亮下一節。

## 學測倒數

- 目標日期：**2027 年 1 月 22 日**（116 學年度學測第一天，考期 1/22–1/24）。
- 計算方式**不算當天**，例如 2026/11/24 顯示 58 天。
- 倒數到 0 之後自動隱藏。

## 防殘影（防烙印）

投影機若是 3LCD 機種，長時間顯示固定的高對比畫面可能產生殘影。這個網頁用「像素遮罩」處理：

- 畫面上方蓋一層看不見的遮罩，每 2×2 個像素裡遮掉 1 個。
- 被遮的位置每分鐘換一次，依序：

```
右下      左下      右上      左上
O O       O O       O X       X O
O X  →    X O  →    O O  →    O O  → 回到右下
```

- 每個像素每 4 分鐘裡有 1 分鐘是暗的，亮度保留約 75%。
- 位置依照實際時間計算，重新整理網頁也會接著同一個循環。

**重要：這個效果要「一個網頁像素 = 一個投影像素」才會正確。** 電腦輸出的解析度必須設成投影機的原生解析度，Windows 的顯示縮放也建議用 100%。如果解析度被縮放，遮罩會變成模糊的灰色或出現波紋，失去防殘影效果。

其他建議：放學後關機，不要 24 小時開著；燈泡式投影機可在選單開 ECO 模式延長燈泡壽命。

## 瀏覽器需求

- 建議 **Chrome 或 Edge 133 以上**。版面上「字頂切齊」用到 `text-box` 這個較新的 CSS 功能，舊版瀏覽器仍能正常顯示，只是字的上下邊緣對齊會差幾個像素。
- 時間來自電腦本機時鐘，請確認電腦時間正確（Windows 建議開啟自動校時）。
- 建議關閉電腦的自動睡眠和螢幕關閉，否則一段時間後畫面會消失。

## 如何修改

所有設定都在 `index.html` 裡，改完存檔、推上 GitHub，網頁約一兩分鐘後更新。

### 換課表

找到 `SCHEDULE`，1 到 5 分別是週一到週五，每個科目寫兩個字：

```js
const SCHEDULE = {
  1: ['國文','英文','補強','補強','化學','化學','數學','物理'],
  ...
};
```

科目需要剛好兩個字（第一個字顯示大、第二個字顯示小）。

### 換上課時間

```js
const STARTS = ['8:00','9:00','10:10','11:10','13:10','14:10','15:10','16:10'];
const LEN = 50;   // 每節分鐘數
```

下課切段的規則：兩節之間剛好 70 分鐘會被當成午休切成 30+30+10，其他空檔每 10 分鐘切一段，所以空檔長度需要是 10 的倍數。

### 換考試日期

```js
const EXAM = new Date(2027, 0, 22);   // 月份從 0 開始算，0 = 一月
```

### 調整版面

在檔案最上方 `:root` 裡：

| 變數 | 作用 | 目前值 |
|---|---|---|
| `--seam` | 中間縫的寬度 | `3vw`（螢幕寬 3%） |
| `--edge` | 左右外側留白 | `1vw` |
| `--col` | 基準尺寸，改它所有字一起放大縮小 | `min(2.8vw, 4.6vh)` |
| `--tsize` | 時間字級 | `--col` × 2.1 |
| `--top` | 左半上方留白 | 時間字級 × 0.12 |
| `--rtop` | 右半額外上方留白 | 等於 `--top`（所以右邊總共是左邊兩倍） |
| `--stroke` | 中文描邊粗細，越大越粗 | `0.015em` |

個別字級在 CSS 裡以 `calc(var(--col) * 倍數)` 表示，例如倒數是 `1.91`、日期是 `0.9`。

## 已知限制

- 國定假日、補課日、段考等特殊日子不會自動判斷，照星期幾顯示課表。
- 只在畫面上方 1/6 顯示，下方是全黑，投影機燈泡仍然在亮。
- 這個 repo 和網頁是公開的，任何人都看得到內容（包括課表）。
